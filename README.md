# Furutec website — test product

This repository is the **test / review copy** of the Furutec website and its content editor.
The live site (furutec.com.my) is deployed from it by hand and keeps its own `config/config.php`
with a real password; that file is never committed here.

## Reviewing the editor

Open the test deployment's `/editor/` URL. The login form is pre-filled — just click **Sign in**.

| | |
|---|---|
| Username | `demo` |
| Password | `furutec-demo` |

Anything saved or published on the test copy stays on the test copy.

## Layout

- `index.html`, `product.html`, `portfolio.html`, `portfolio-track-record.html`, `quote.html` — published pages (generated by the editor's Publish)
- `editor/` — the PHP content editor (templates in `editor/templates/`, logic in `editor/lib/`)
- `data/field-map.php` — what is editable; `data/content.php` — the saved content
- `assets/` — images, videos, documents
